GUI Application: Cochlear Cross-sectional Organ of Corti Model

This application provides a graphical user interface (GUI) for genrating mechanical responses and plotting the Maximum Power Filtering functions  at three cochlear locations. 
Download the Matlab application above along with images.

1. Select one of the three available cochlear locations; 
2. Click "show parameters value" button to display the cochlear parameters in the table;
3. Click 'plot responses' button to show the basilar membrane response at point E, TM shear and bending responses at point F in Fig (a);
4. Click 'plot MPF function' buttion to show the maximum power filtering functions.

More details can be found in the paper "Band-pass maximum power filtering in cochlear amplification".

Requirement: Matlab
